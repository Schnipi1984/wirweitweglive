# WirWeitWeg – Projektregeln für Claude Code

**Es gibt nur eine Quelle:** die Master-Bibel. Diese Datei enthält bewusst keine eigenen Regeln mehr, damit nie wieder zwei Dokumente gegeneinander laufen.

## Vor jeder Arbeit an diesem Repo

1. Master-Bibel aus dem claude.ai-Projekt **"wirweitweglive"** lesen, Pfad `claude/master-bibel-wirweitweg-15.0.md` (Dateiname bleibt stabil, auch wenn die Versionsnummer im Dokument selbst steigt — aktuell Version 15.11, Stand 18.10.2026).
2. Diese Bibel regelt alles: Aufbau jeder Seite, Design-System, SEO, Technik, Deploy-Workflow, die Stimme (wie ein Text als Marc & Fabienne geschrieben wird, inklusive der Anti-KI-Checkliste), die Wahrheitsregel, und den Ablauf bei fehlenden Fakten.
3. **Es gibt keine gesperrten Seiten mehr** (Stand 18.10.2026). index.html, weltreise-planung.html und idee-zeitplan.html werden wie jede andere Seite bearbeitet, ohne vorherige Rückfrage, ob die Datei angepasst werden darf. Sie bleiben nur noch Design-Referenz für Nav, Header, Footer und Logo.
4. Bei fehlenden Fakten (eine Zahl, ein Erlebnis, ein Preis, das nur Marc oder Fabienne liefern können): **immer konkret, nummeriert und einzeln fragen** — nie eine offene, vage Bitte um Input. Dann auf Antwort warten, nie erfinden.
5. Vor dem Deploy: die fertige Seite zeigen, auf Marcs kurzes ok warten. Das ist der einzige Moment vor dem Deploy, an dem eine Bestätigung nötig ist.

## Wenn die Bibel nicht erreichbar ist

Falls das claude.ai-Projekt aus diesem Kontext heraus nicht lesbar ist: Marc direkt fragen, ob er die aktuelle Bibel-Datei bereitstellen kann (sie liegt auch lokal im Repo-Ordner als `WirWeitWeg_Master_Bibel.md`). Niemals aus dem Gedächtnis oder aus einer älteren, abweichenden Quelle arbeiten.
